# APP_CSCAM — CSCAM 사업부별 홈페이지

CSCAM의 사업부별 웹사이트를 관리하는 프로젝트입니다.
비개발자(사령관)가 AI 에이전트와 함께 만들고 · 업데이트하고 · 배포합니다.

## 폴더 구조

```
APP_CSCAM/
├── README.md          ← 지금 이 파일
├── docs/              ← 프로젝트 문서 (수정내역 등)
├── shared/            ← 사업부 공통 "컨셉"(디자인·부품) 들어갈 자리 (미래)
└── sites/             ← 사업부별 사이트
    └── 3dprinter/     ← 금속 3D프린터 사업부 (첫 번째)
        ├── index.html ← 메인 페이지
        ├── images/    ← 사진
        └── uploads/   ← 영상 등
```

## 계획된 사이트 (사업부)
- [x] `3dprinter` — 금속 3D프린터 (진행 중)
- [ ] `cnc` — CNC 사업부
- [ ] `machine` — 기계 사업부

각 사이트는 **비슷한 컨셉, 독립된 내용**으로 만들고, 나중에 서브도메인
(`3dprinter.cscam.co.kr` 등)으로 각각 배포합니다.
