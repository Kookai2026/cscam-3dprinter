## 3. 🚀 로컬 수정 후 웹사이트 반영 방법 (Git 명령어)

새 로컬 경로 `S:/APP_CSCAM`은 아직 깃허브 원격 저장소 주소(Remote)가 설정되지 않았을 수 있습니다. 처음 배포를 연동할 때는 **원격 저장소 설정** 단계를 먼저 진행해 주세요.

### ① 최초 1회 실행 (깃허브 원격 저장소 연결)
```bash
# 1. 새로 만든 로컬 폴더로 이동
cd "S:/APP_CSCAM"

# 2. 깃허브 원격 저장소 등록 (origin이라는 이름으로 주소 연결)
git remote add origin https://github.com/Kookai2026/cscam-homepage.git
```
> **주의**: 기존 깃허브 저장소에 있던 예전 단일 페이지 구조가 이 새로운 다중 사업부 구조(`sites/`, `shared/` 등)로 **완전히 덮어씌워지며 업그레이드**됩니다.

### ② 상시 반영 실행 (수정 사항 업로드)
파일을 수정하고 저장하신 후, 아래의 **깃(Git) 명령어**를 실행하면 깃허브 서버가 새로운 구조를 자동 빌드하여 30초 내에 웹사이트에 반영합니다.

```bash
# 1. 깃 폴더로 이동 (필요시)
cd "S:/APP_CSCAM"

# 2. 변경된 파일 전체 스테이징 (루트 index.html 및 sites/ 하위 모든 변경 사항 포함)
git add .

# 3. 변경 사항 메시지와 함께 기록 (커밋)
git commit -m "원하는 수정 내역 설명 입력"

# 4. 깃허브로 전송 (원격 저장소에 업로드)
# 최초 푸시인 경우: git push -u origin main
# 이후에는 간단히: git push
git push -u origin main
```

### 💡 깃 명령어 세부 용어 공부
1. **`git add .`**: 수정하거나 새로 생성한 모든 파일을 다음 깃 기록(스냅샷)에 포함하도록 지정(Staging)하는 명령어입니다. 점(`.`)은 현재 폴더 안의 모든 변경 사항을 의미합니다.
2. **`git commit -m "메시지"`**: 준비된 변경사항을 로컬 데이터베이스에 확정 기록(Commit)하는 명령어입니다. 이때 작성하는 메시지는 무엇을 바꿨는지 나중에 알아볼 수 있는 이름표 역할을 합니다.
3. **`git push`**: 로컬에 기록한 커밋들을 원격지 서버인 깃허브(GitHub) 저장소로 밀어올려(Push) 동기화하는 명령어입니다. 깃허브는 `push`가 일어나는 즉시 웹사이트를 새로 빌드하여 배포합니다.

## 4. 🛠️ 작업 내용 요약 히스토리 (v16 기준)
* **반응형 햄버거 메뉴 및 프리뷰 툴바**: 모바일 해상도 대응 햄버거 메뉴 추가 및 PC 접속 시 모바일 프레임으로 검토 가능한 토글 툴바 구현.
* **기종 모델명 갱신**: AnyX-M200을 현업 기준에 맞게 `AnyX-M250`으로 전면 변경.
* **수치 표기 표준화**: 조형 사양 `mm` 및 세로축 `(H)` 표시 보강, 레이저 사양 `1000W(Dual)` 한 줄 정렬.
* **리스크 수치 정제**: 과한 수치 표현(상대밀도 99.5%, 0.05mm 수준 등)을 순화하여 문구 리스크 관리.
* **컨테이너 가독성 보강**: 보증 텍스트 및 협력 기관 강조 가독성 개선, 모바일 글씨 잘림 버그 수정.
* **고객사 로고 루프 개선**: 롤링 스크롤 끊김 없는 Seamless Loop 완성.

## 5. 🤖 AI 에이전트(Claude Code 등)에게 배포를 요청하는 프롬프트 템플릿

AI 코딩 어시스턴트(예: Claude Code, Antigravity 등)에게 현재 수정된 모바일 버전 작업을 깃허브에 배포해 달라고 바로 요청할 때 복사해서 쓸 수 있는 프롬프트 양식입니다.

### 📋 복사해서 사용할 프롬프트 예시

```text
지금까지 작업한 홈페이지 모바일 버전 개선 사항을 깃허브(GitHub Pages)에 배포해 줘. 
아래 순서대로 작업을 진행하고 각 단계 결과를 공유해 줘:

1. 로컬 작업 경로를 "S:/APP_CSCAM"으로 인식하고 이동해 줘.
2. `git remote -v`를 확인해서 원격 저장소(origin)가 설정되어 있지 않다면, `git remote add origin https://github.com/Kookai2026/cscam-homepage.git` 명령으로 저장소를 연결해 줘.
3. `git status`와 `git diff`를 실행해서 모바일 대응을 위해 변경된 파일들이 무엇인지 확인해 줘. (루트의 리다이렉트용 index.html 파일 및 sites/3dprinter/ 폴더 이하의 변경내역 등)
4. 변경 사항이 확인되면, 변경 내용(예: 모바일 반응형 UI 개선, clamp 타이포그래피 적용 및 폴더구조 다각화 등)을 설명하는 명확한 커밋 메시지를 작성해서 `git add .` 및 `git commit`을 수행해 줘.
5. 마지막으로 `git push -u origin main`을 실행해서 원격 GitHub 저장소에 밀어 올려 배포를 갱신해 줘.
6. 배포가 완료되면 https://kookai2026.github.io/cscam-homepage/ 및 https://kookai2026.github.io/cscam-homepage/sites/3dprinter/ 사이트에 변경 사항이 잘 반영되었는지 확인하고 보고해 줘.
```
