# 05. 폴더 구조 (APP_CSCAM)

> [!info] 이 문서는
> 프로젝트 실제 폴더를 `S:\APP_CSCAM` (= `C:\Active\APP_CSCAM`)에 새로 세팅한 기록입니다.
> 배경 구조는 → [[03_전체구조와_로드맵]]

## 왜 폴더를 새로 정리했나
기존 작업 폴더(`02_Work/260731_홈페이지 개선안`)는 **약 320MB 중 대부분이 군더더기**였다
(147MB 압축파일, 42MB 중복영상, 42MB 원본참고, 20MB 중복이미지 등).
깨끗한 구조에서 **처음부터** 제대로 하기 위해, 필요한 것만(약 40MB) 골라 새 폴더로 옮겼다.
> 원본 폴더는 **삭제하지 않고 백업으로 보존**함.

## 최종 폴더 구조
```
APP_CSCAM/
├── README.md          프로젝트 소개
├── FOLDER_MAP.md      폴더 지도 (헷갈리면 여기)
├── .gitignore         git이 무시할 파일
├── docs/              프로젝트 문서
├── shared/            🧩 사업부 공통 "컨셉" (css/js/images) — 지금은 빈 자리
└── sites/             🌐 사업부별 사이트
    ├── 3dprinter/     ✅ 금속 3D프린터 (진행 중, 실제 페이지 있음)
    ├── cnc/           ⬜ CNC 사업부 (준비중 자리표시 페이지)
    └── machine/       ⬜ 기계 사업부 (준비중 자리표시 페이지)
```

## 핵심 규칙
| 무엇 | 어디 |
|---|---|
| 모든 사이트 공통(로고·색·부품) | `shared/` |
| 한 사업부 전용 내용·사진 | `sites/<사업부>/` |
| 문서·이력 | `docs/` |

## 배포 계획 (서브도메인)
`sites/3dprinter/` → `3dprinter.cscam.co.kr` / `cnc/` → `cnc.cscam.co.kr` / `machine/` → `machine.cscam.co.kr`

## 이번에 배운 것
- **미래 폴더를 미리 만들어 둔다**: CNC·기계는 아직 내용이 없어도 빈 골격 + "준비 중" 페이지를 미리 둠 → 나중에 채우기만 하면 됨.
- **빈 폴더는 `.gitkeep`**: git은 빈 폴더를 기억 못 하므로, 자리표시 파일 하나를 둬서 폴더가 사라지지 않게 함.
- **git 첫 커밋 = 복원 지점**: 깨끗한 상태를 저장해두면 언제든 이 시점으로 되돌릴 수 있음.
- CNC·기계의 자리표시 페이지는 **일부러 깨끗한 최소 HTML**로 작성 → "좋은 HTML은 이렇게 생겼다"는 비교 견본.

## 상태
- git 저장소 초기화 + 첫 커밋 완료.
- 3D프린터 페이지: 새 위치에서 렌더링 정상 확인(폰 390px). 이전에 고친 폰트도 유지됨.
