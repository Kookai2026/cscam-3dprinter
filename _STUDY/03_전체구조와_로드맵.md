## 🎯 최종 그림 (목표 구조)

서브도메인 방식 + 공유 컨셉 패키지. 저장소는 하나(모노레포).

```
cscam-web/                        (저장소 1개 = 모노레포)
├── packages/
│   └── concept/                  ★ "비슷한 컨셉" = 모든 사이트가 공유
│       ├── tokens.css            색·폰트·간격 (디자인 토큰)
│       ├── BaseLayout            히어로·섹션 골격
│       └── components/           헤더·푸터·제품카드·스펙표·문의폼
│
├── sites/
│   ├── 3dprinter/                → 3dprinter.cscam.co.kr   ★ 지금 것
│   │   ├── pages/
│   │   └── data/                 이 사업 콘텐츠·사진
│   ├── cnc/                      → cnc.cscam.co.kr         (나중)
│   └── machine/                  → machine.cscam.co.kr     (나중)
│
└── (워크스페이스 설정)
```

**규칙 하나만 기억:**
- `packages/concept` = 고치면 **모든 사이트에 동시 반영** (공유 컨셉)
- `sites/*` = 각 사업부 **콘텐츠만** (서로 독립)

| 대표님 방침 | 이 구조에서 어떻게 지켜지나 |
|---|---|
| "컨셉은 비슷하게" | `packages/concept` 공유 |
| "각각 다르게" | `sites/*` 독립 콘텐츠 |
| "본체 페이지 없이" | 회사 홈 없음, 형제 사이트만 |
| 서브도메인 독립 배포 | 사이트별 개별 빌드·배포 |
| CNC 추가 | `sites/cnc/` 폴더 + 서브도메인 연결만 |

## 🪜 단계별 로드맵

### Phase 0 — 순수 HTML로 정리 & 기본기 (🔴 지금 여기)
> 목표: 도구 없이 HTML/CSS를 이해하고, 현재 페이지의 군더더기를 정리한다.
- [ ] HTML 뼈대가 무엇인지 눈으로 익히기
- [ ] **모바일 깨짐 수정** (미디어 쿼리 추가) → [[04_작업일지]] 2026-07-31
- [ ] 안 쓰는 파일·중복 정리 (`Index.dc.html` 등, 42MB 영상 원본 등)
- [ ] `<title>`·설명·공유 미리보기(og) 메타태그 넣기
- **끝나면:** 화면은 지금과 비슷하되, 깨끗하고 모바일에서 안 깨지는 HTML 1벌.

### Phase 1 — 공통 "컨셉" 분리
> 목표: 헤더·푸터·색·폰트·카드를 **재사용 가능한 부품**으로 뽑는다.
- [ ] 색·폰트·간격 → 디자인 토큰으로 모으기
- [ ] 반복되는 카드·버튼·섹션 → 컴포넌트로 추출
- [ ] 제품 내용 → 데이터로 분리 (콘텐츠 ↔ 레이아웃 분리)
- **끝나면:** 컨셉을 한 곳에서 관리. CNC가 이걸 그대로 가져다 쓸 준비 완료.

### Phase 2 — 사업별 구조 + 서브도메인 배포
> 목표: 모노레포 골격을 세우고 `3dprinter.cscam.co.kr`로 실제 배포.
- [ ] `packages/concept` + `sites/3dprinter` 구조로 재조립
- [ ] 정적 사이트 생성기(Astro 등) 도입 검토
- [ ] DNS 연결 + 자동 배포

### Phase 3 — CNC · 기계 사업부 확장
> 목표: 검증된 틀을 복제해 새 사업부를 빠르게 추가.
- [ ] `sites/cnc/` 복제 → 데이터 교체 → `cnc.cscam.co.kr` 연결
- [ ] `sites/machine/` 동일 반복

### Phase 4 — (필요 시에만) 동적 기능
- [ ] 문의 폼(폼 서비스), 필요하면 챗봇·검색 등은 서버리스로

> [!important] 이 순서의 장점
> 각 단계가 이전 단계를 **버리지 않는다.** Phase 0의 깨끗한 HTML 위에 컨셉을, 그 위에 구조를, 그 위에 확장을 얹는다. 매몰비용 없음.
