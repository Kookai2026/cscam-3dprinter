**반응형 글자 크기 원칙 — `clamp(최소, 기준vw, 최대)`**
- 최소값은 **폰 기준**으로 (예: 히어로 h1 `clamp(22px,5vw,54px)`).
- 최소값을 PC 기준(32px 등)으로 두면 폰에서 안 줄어든다. ← 자주 하는 실수.

## 📱 모바일 반응형 원칙 (필수 체크리스트)
> 이 페이지에서 실제로 겪고 정리한 규칙. 새 사이트도 동일 적용.

1. `<meta name="viewport" content="width=device-width, initial-scale=1">` 필수.
2. 모바일 규칙은 **`@media (max-width:992px)`** 에 모은다 (인라인 금지 — `!important`에 덮임).
3. **다단 그리드 → 모바일 1열** (2열 유지 필요한 것만 예외).
4. **큰 gap(24px+) 가로 flex → 세로 쌓기**(`flex-direction:column`).
5. **`section * { min-width:0 }`** — 자식 내용이 칸보다 넓어져 삐져나가는 것 방지.
6. **큰 카드 안쪽 여백**(32~44px) → 모바일 좌우 20px로 축소.
7. **고정 큰 글씨/번호** → 클래스로 잡아 축소, 필요시 `white-space:normal`로 줄바꿈 허용.
8. 검증: **390px 폰 뷰포트 렌더링**으로 확인, 가로 오버플로 0.
