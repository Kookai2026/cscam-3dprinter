Core Technology

왜 피에조(Piezo) 방식 문자마킹기인가?

씨에스캠이 적용하는 피에조 압전 헤드 엔진은 구형 DOD 밸브 개방 방식 대비 압도적인 해상도와 친환경성을 제공합니다.

초정밀 고선명 마킹

0.282mm 도트 사이즈의 미세 제어로 바코드, AR-CODE 및 20mm 이하 소문자까지 판독 불량 없이 선명하게 각인합니다.

작업 환경 개선 및 무독성

독성 강한 MEK 유기용제 대신 인체에 유해 성분이 없는 친환경 오일 잉크를 적용하여 폐액 발생을 억제하고 실내 가동 환경을 개선합니다.

획기적인 소모품비 절감

솔벤트를 분사해 헤드를 청소할 필요가 없으므로 정기 소모품 비용이 크게 감소하며, 24시간 가동 시 연속 프린트 안정성이 우수합니다.

Stationary System

고해상도 고정식 문자마킹 시스템

선박 전처리 강판 컨베이어 라인 상단에 영구 고정되어 통과하는 플레이트 전체 또는 중앙 ID를 정밀 마킹합니다.

고정식 강재 문자마킹기 (전체 마킹기 / ID 마킹기)

고정 갠트리 프레임에 초정밀 피에조 마킹 헤드를 배열하여 강재가 통과하는 순간 실시간 가속 및 트리거 동작으로 텍스트 및 조립용 심볼을 마킹합니다. 최대 17개 마킹 헤드가 장착되어 4.8m 너비의 대형 판판 전체를 한 번에 커버합니다.

  • ✔전체 마킹기 (Full Surface): 마킹 헤드 17세트 장착, 유효 마킹 범위 최대 4,800mm (강재 ID + 소부재 분할 표기 최적화)
  • ✔ID 마킹기 (Central ID): 마킹 헤드 4세트 장착, 유효 마킹 범위 최대 1,128mm (강재 중심 식별용 문자 및 코드 전용)
  • ✔실시간 물리 계측 모듈: 초음파 센서를 적용한 강재 두께 자동 검출 (6T ~ 120T) 및 레이저 뒤틀림 각도 측정 모듈 기본 연동

Mobile Panel System

대면적 이동식 판넬 문자마킹 시스템

갠트리 레일 위를 자동 질주하며 대형 구조 주판(Panel) 위에 조립 유도선(라인) 및 식별용 문자를 고속 인쇄합니다.

주판 라인마킹 & 라벨링 시스템 (이동형 Gantry)

선박 블록 조립 공장의 대형 주판 영역을 정밀하게 이동하면서 각 소부재가 안착할 정밀 용접/가이드 경계선을 먹줄 작업 대신 잉크젯으로 인쇄하고, 부재 식별 마크 및 스마트 조립 스캔용 AR-CODE/QR-CODE를 완벽하게 마킹하는 첨단 스마트 조선 공정 장비입니다.

  • ✔대면적 자동 주행 제어: 야드 크기에 맞춰 설계된 레일식 갠트리 프레임 위에서 5축 서보 구동을 통한 광역 스캔 제어
  • ✔복합 라인 & 문자 인쇄: 두께감 있는 유도 라인 마킹 모듈과 고해상도 정보 문자 피에조 헤드 복합 제어
  • ✔지능형 스마트 코드 지원: 삼성중공업 판넬라인 등에서 공인 테스트를 마친 AR-CODE / QR-CODE 마킹 검증 완료

Smart Data Workflow

씨에스캠 CAD & IMD 마킹 데이터 흐름

선박 설계국 CAD 데이터부터 가공 현장 마킹기까지 실시간 전송 처리하는 지능형 데이터 스케줄러

자동화 마킹 처리 및 간편 데이터 매칭

설계 부서에서 로딩한 선박 도면(CAD Data)은 IMD(Initial Marking Data) 서버로 흘러 들어가 지능형 알고리즘을 거칩니다. 이 알고리즘은 문자 중복 회피, 가변 위치 연산, 대칭 처리를 자동으로 끝마칩니다.

중공업 네트워크망(CAD/IMD 서버) 구축이 어려운 극한의 야드 환경의 경우, 작업자가 매일의 철강 생산 계획 데이터를 USB 드라이브에 넣어 마킹룸 내의 Data PC에 신속하게 업로드하여 바로 마킹 작업을 시작할 수 있는 편의 기능이 기본 내장되어 있습니다.

[1] CAD Server설계국 원본 선박 부재/강재 마크 데이터 생성 및 관리
[2] IMD Server문자열 변환, 중복 검출 및 대칭형 부재 회전 연산 처리
[3] Data PC현장 운영자용 모니터링 프로그램 (마킹 진행상황 스케줄링)
[4] Control PC서보 제어기 및 피에조 헤드 17세트 전압/경화기 출력 제어
